# FF Barbershop Telegram Bot 

Telegram-бот для записи клиентов в барбершоп.
![Demo](demo.gif)
## Возможности

- 📞 Запись на услугу
- 💇 Выбор услуги
- 👤 Выбор мастера
- 📅 Выбор даты
- ⏰ Выбор времени
- ✅ Подтверждение записи
- 📋 Просмотр своих записей
- ✏️ Изменение записи
- ❌ Удаление записи
- 💰 Просмотр прайса
- 📍 Контакты и информация о салоне

## Технологии

- Python
- python-telegram-bot
- JSON для хранения данных

## Запуск проекта

Установить зависимости:

```bash
pip install -r requirements.txt
```
